# SIDIAN --- PRODUCT PRINCIPLES

**Version :** 1.0\
**Status :** OFFICIAL\
**Owner :** Product

------------------------------------------------------------------------

# WHY

Sidian n'est pas un logiciel de gestion classique.

Sidian est un copilote financier alimenté par l'IA.

Ces principes guident toutes les décisions produit, UI et UX.

------------------------------------------------------------------------

# 1. L'IA EST LE PRODUIT

L'IA n'est pas une fonctionnalité.

Elle constitue le point d'entrée principal de Sidian.

------------------------------------------------------------------------

# 2. UNE ACTION PRINCIPALE PAR ÉCRAN

Chaque écran doit guider naturellement l'utilisateur vers une seule
action dominante.

------------------------------------------------------------------------

# 3. LE LOGICIEL TRAVAILLE AVANT L'UTILISATEUR

L'interface doit donner le sentiment que l'agent est déjà prêt à agir.

------------------------------------------------------------------------

# 4. RÉDUIRE LA CHARGE MENTALE

Supprimer toute information qui n'aide pas une décision ou une action.

------------------------------------------------------------------------

# 5. LE VIDE EST UNE FONCTION

Ne jamais remplir un espace simplement parce qu'il est disponible.

------------------------------------------------------------------------

# 6. LA TYPOGRAPHIE AVANT LA DÉCORATION

La hiérarchie repose d'abord sur : - la taille - le poids - l'espacement

Jamais sur des effets graphiques.

------------------------------------------------------------------------

# 7. LES DONNÉES SONT CONTEXTUELLES

Afficher uniquement les informations utiles à l'instant présent.

Pas de dashboard rempli de KPI inutiles.

------------------------------------------------------------------------

# 8. LE COMPOSER EST LE CŒUR DU PRODUIT

Le composer est toujours l'action principale.

Tout le reste le soutient.

------------------------------------------------------------------------

# 9. LES SUGGESTIONS SONT DES INTENTIONS

Les actions rapides ne sont pas de la navigation.

Elles représentent des tâches que l'agent peut accomplir.

------------------------------------------------------------------------

# 10. PREMIUM = SIMPLICITÉ

Le premium vient : - de l'espace - des proportions - de la cohérence -
des détails

Jamais de la décoration.

------------------------------------------------------------------------

# 11. ACCESSIBILITÉ PAR DÉFAUT

Tout nouveau composant doit être utilisable : - au clavier - avec un
contraste élevé - sur mobile - avec des états de focus visibles

------------------------------------------------------------------------

# 12. COHÉRENCE AVANT ORIGINALITÉ

Une bonne idée qui casse la cohérence n'est pas une bonne idée.

------------------------------------------------------------------------

# 13. CHAQUE PIXEL A UNE UTILITÉ

Avant d'ajouter un élément, poser la question :

« Aide-t-il l'utilisateur à comprendre, décider ou agir ? »

Si la réponse est non, il ne doit pas être ajouté.

------------------------------------------------------------------------

# DÉCISION

En cas de conflit entre esthétique et simplicité, la simplicité
l'emporte.

En cas de conflit entre quantité d'informations et compréhension, la
compréhension l'emporte.

En cas de doute, revenir à ces principes avant toute évolution du
produit.
